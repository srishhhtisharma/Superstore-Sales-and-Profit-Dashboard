# Superstore Sales and Profit Dashboard 📊

This project is an interactive Excel dashboard built using the Superstore dataset.

## 🔍 Overview
The dashboard provides insights into sales and profit performance across different regions, categories, and products.

## 🚀 Features
- Sales & Profit analysis by region
- Top 5 products by sales
- Monthly sales trend
- Interactive slicers (Category & Region)

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Slicers
